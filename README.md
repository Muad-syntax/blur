# ✌️ Peace Blur Detector

A simple Computer Vision project that automatically blurs your webcam when a peace sign (✌️) is detected.

Built using Python, OpenCV, MediaPipe and Pygame for playing music.

## Features

* Real-time webcam detection
* Peace sign recognition
* Automatic full-screen blur effect
* Lightweight and beginner-friendly project

## Installation

Clone this repository:

```bash
git clone https://github.com/Muad-syntax/blur.git
cd fotoKitaBlur
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run

```bash
python blur.py
```

Press `ESC` to close the application.

## Tech Stack

* Python
* OpenCV
* MediaPipe
* Pygame
